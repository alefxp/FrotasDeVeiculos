# Sistema de Controle de Frota 🚗

Projeto desenvolvido em Java com o objetivo de praticar programação orientada a objetos e desenvolver um sistema simples de controle de frota empresarial.

## 📌 Status do projeto

**Versão 1.0 — Em desenvolvimento**

Esta é a primeira versão do projeto. O sistema está sendo desenvolvido gradualmente e receberá novas funcionalidades e melhorias ao longo do tempo.

## ⚙️ Funcionalidades atuais

- Cadastro inicial de setores e veículos.
- Identificação do setor por ID.
- Listagem de veículos com modelo, placa e disponibilidade.
- Validação de IDs informados pelo usuário.
- Tratamento de entradas inválidas com `try-catch`.

## 🚀 Melhorias planejadas

- Implementação completa do sistema de reservas.
- Consulta das reservas por setor.
- Melhorias na organização e validação do código.
- Possível integração futura com um banco de dados para persistência das informações.

## 🛠️ Tecnologias

- Java
- IntelliJ IDEA
- Git e GitHub

## 🎯 Objetivo

Este projeto faz parte da minha jornada de aprendizado em programação e será atualizado conforme eu adquirir novos conhecimentos e implementar novas funcionalidades.
